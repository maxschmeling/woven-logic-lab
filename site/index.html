DESIGN

Little language, explained

Begin with INPUT a, b. Then write one output per line: lamp = a AND b.

  • AND: both on. OR: either on.
  • XOR: exactly one on. NOT: flip it.
  • Use ( ) to group, 0 / 1 for constants, and # for comments.
  • Priority: NOT → AND → XOR → OR. Symbols ! & ^ | also work.
  • Names ignore letter case. Outputs may reference inputs, not each other.

“If armed and the door is open, sound the alert” becomes alert = armed AND open.

This is combinational logic: no loops, timers, variables that remember, or arbitrary Python/JavaScript. To change the physical program, change the pattern.

INSPIRED BY APOLLO. NOT A REPLICA.

The program
is the pattern.

A circuit can calculate an answer.
A memory can remember every answer.

A lookup table is a little logic machine.

For three binary inputs, there are only eight possible combinations. We calculate the result of each one, then encode those answers into rows. The input selects a row; that row gives you the outputs. The “compilation” is turning your expressions into this finite table.

What was actually woven for Apollo?

Wires threaded through or around magnetic cores encoded bits of fixed, read-only memory. That memory stored instructions and data; it was not the entire computer. A separate processor executed instructions, and specialized circuitry read the magnetic signals.

Our yarn model uses the same through/around idea, but its rings are not magnetic and a person reads it. Our electronic build is a woven diode ROM: diode connections store the bits. The Arduino selects and reads a row; it does not evaluate your original equations. Neither build is an Apollo core-rope replica.

Why stop at three inputs?

Each additional input doubles the rows. Three inputs need 8 rows; ten need 1,024. This is a tabletop learning tool, not a compiler for full applications. Stateful programs need extra memory and a clock, which these builds do not include.

Want to explore real magnetic core rope?

Start with the restoration work linked below. A magnetic implementation requires appropriate ferrite material, pulse-drive circuitry, and sense amplification; it cannot be substituted into our DC diode reader. We intentionally do not present an untested pulse circuit as a beginner construction plan.
